# ShadowFox Java Internship Projects

This repository contains five Java-based projects completed as part of the ShadowFox Internship program.


1. Enhanced Console-based Calculator

**Description**:  
A console-Based calculator supporting:
- Basic Arithmetic (Add, Subtract, Multiply, Divide)
- Scientific Functions (Square Root, Power)
- Unit Conversions (Temperature, Currency)

**Key Concepts**:  
Java methods, user input, exception handling, math utilities.

---

2. Contact Management System

**Description**:  
A simple command-line contact manager that allows users to:
- Add new contacts
- View all contacts
- Update or delete existing contacts

**Key Concepts**:  
ArrayList usage, CRUD operations, user interaction, modular functions.

---

3. Bank Account Management System with JUnit Testing

**Description**:  
This system allows the user to:
- Create bank accounts
- Deposit and withdraw money
- View balance and transaction history

✅ Includes **JUnit test cases** for validating core operations.

**Key Concepts**:  
OOP principles, unit testing with JUnit, encapsulation, TDD basics.

---

4. Library Management System with SQLite

**Description**:  
A console-based Library System with:
- User account system (Admin/User)
- Book add/delete/search functionalities
- SQLite database for persistent storage

**Key Concepts**:  
JDBC with SQLite, role-based access, data persistence, SQL integration.

---

5. Real-Time Chat Application

**Description**:  
A Java-based socket programming project that enables:
- Real-time messaging
- Multi-user chat room using TCP sockets
- Simple Swing GUI for messaging interface

**Key Concepts**:  
Socket programming, real-time communication, multithreading, basic GUI with Swing.
